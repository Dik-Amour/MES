## 工具经验（重要）

- 本机 `tencent-local-office-edit` skill 的 `edsdk.py` 可用于读写本地 docx：
  - `open_file` / `doc_resolve_document_structure` / `doc_replace_text` / `doc_set_table_cells` / `doc_replace_image` / `save_file` / `close_file`
  - `doc_replace_image` 需要 `idx` + `old_image_url` + `new_image_path`；替换后**自动沿用原图显示尺寸**（不会按新图比例重排），所以新图宽高比要尽量贴近原图
- 陷阱：`save_file` 直接写桌面路径会失败（文件被编辑器占用）。可靠做法是 `save_file` 到临时目录，再 `close_file`，最后用 Python `shutil.copyfile` 拷贝到桌面。
